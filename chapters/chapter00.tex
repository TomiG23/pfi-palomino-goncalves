\chapter{Introducción}

\section{Objetivo General}

Desarrollar un prototipo funcional que permita transformar datos operativos de tiendas de e-commerce en recomendaciones accionables, orientado a emprendimientos y PyMEs que no cuentan con recursos para contratar analistas de negocio, con el fin de mejorar la toma de decisiones comerciales en la Ciudad Autónoma de Buenos Aires durante el año 2026.

\section{Objetivos Específicos}

El presente proyecto se plantea los siguientes objetivos específicos:

\begin{enumerate}
    \item Optimizar la eficiencia operativa de los comercios mediante la automatización del procesamiento de datos de ventas e inventario.

    \item Incrementar el volumen de ventas a través de la identificación de patrones de comportamiento que deriven en estrategias comerciales precisas.

    \item Mejorar el nivel de engagement y la experiencia del usuario final mediante la generación de recomendaciones personalizadas y oportunas.

    \item Validar la utilidad del sistema comparando la capacidad de respuesta de los usuarios ante recomendaciones directas versus dashboards descriptivos tradicionales.
\end{enumerate}

\section{Alcance}

El proyecto contempla el diseño y desarrollo de un prototipo funcional con cobertura geográfica limitada a la Ciudad Autónoma de Buenos Aires, Argentina, orientado a emprendimientos y comercios de pequeño y mediano tamaño.


\subsection{Componentes Incluidos}

\begin{enumerate}
    \item Identificación del negocio para obtener y asociar sus métricas operativas.

    \item Adquisición y procesamiento de datos de e-commerce a través de integración con la API de Tiendanube.

    \item Desarrollo de un motor de análisis para la detección de patrones y oportunidades comerciales, con enfoque en rubros específicos (gastronomía, indumentaria y electrónica).

    \item Construcción de una interfaz web responsiva integrada al panel de administración de Tiendanube mediante iframe (Aplicación Integrada), que presente recomendaciones accionables optimizadas para diversos dispositivos.

    \item Implementación de un mecanismo de retroalimentación para evaluar el impacto de las recomendaciones ejecutadas.

    \item Consulta diaria a una API pública de tipo de cambio (dólar oficial/blue) como dato de contexto auxiliar para las recomendaciones del rubro electrónica, distinguida de una integración de plataforma: se trata de una única llamada de solo lectura sin autenticación, sin relación de negocio con el proveedor externo, y no reemplaza ni complementa la fuente principal de datos transaccionales, que continúa siendo exclusivamente la API de Tiendanube.
\end{enumerate}

\subsection{Componentes Excluidos}

El foco estará en demostrar la viabilidad de generar valor comercial dentro del ecosistema de Tiendanube, priorizando la claridad y utilidad de las recomendaciones. Quedan fuera del alcance:

\begin{enumerate}
    \item Integraciones múltiples con plataformas externas más allá de Tiendanube.

    \item Carga manual de datos mediante archivos CSV.

    \item Despliegue productivo a escala industrial.

    \item Procesamiento de datos en tiempo real.

    \item Módulos de autenticación, registro de usuarios o gestión de permisos, funcionalidades inherentes a la plataforma Tiendanube.

    \item Publicación formal en la App Store de Tiendanube (queda como trabajo futuro).
\end{enumerate}
